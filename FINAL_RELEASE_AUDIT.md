# Final release audit

**[v0.1.0](https://github.com/yacinezah/torso21-reviewed-field-lines/releases/tag/v0.1.0) — resource release.** No independent annotation-
quality gain is established. The public release preserves the reviewed PNGs,
row mappings, and numerical audit tables byte for byte from the audited candidate.

| Requirement | Evidence |
|---|---|
| Exact reviewed population | 2,400 frozen SEG-R1/refit rows; [provenance](PROVENANCE_RECONSTRUCTION.md), [CSV](manifests/reviewed_masks_manifest.csv), [Parquet](manifests/reviewed_masks_manifest.parquet) |
| Provenance of review versus edits | 1,965 semantic modifications, 435 semantic retentions; 1,820 save-counter records; [per-row transitions](manifests/review_provenance_and_transitions.csv) |
| Upstream identity | All 2,400 matched by archive member size/CRC32; 12 downloaded pairs matched upstream SHA-256, including all three Windows aliases and the ambiguous original |
| Full local payload validation | SHA-256 on every retained original image, original mask and reviewed mask; shape, palette and class-change checks |
| Determinism | Fresh reconstruction of the release payload generated byte-identical CSV, Parquet and 2,400 PNGs; manifests are stable-sorted and versioned |
| Runnable package | Installed into a clean Python 3.11 environment; ten synthetic tests, dependency check, verify, stats, compare, materialize and fixed example rendering passed |
| Numeric and visual QA | [Change results](DATASET_QUALITY_RESULTS.md), [triage flags](quality/validation_flags.csv), [group summaries](quality/group_summary.csv) and [aggregate figure](quality/edit_distributions.svg); eight fixed examples rendered and inspected locally |
| Independent annotation audit | [Frozen protocol](quality/QA_PROTOCOL.md), 240 selected pairs across 45 groups, a reference-only packet, private side assignment and adjudication workflow. No human reference/score, zero independently validated pairs |
| Optional controlled training | Omitted; no independently adjudicated holdout |
| Disclosure boundary | [Source/license ledger](SOURCE_AND_LICENSE_LEDGER.md); only authorized reviewed PNGs and sanitized analysis/tooling are distributable. No original photos, private data/models, reviewer packets or credentials |

There is no claim that all 2,400 labels changed, that all changed pixels
were drawn manually, or that the reviewed candidates are consistently more
accurate. The source archive SHA-256 was not computed over the multi-gigabyte
ZIPs; exact per-member hashes are required at extraction. The source/license
ledger explains CRC32 versus actual upstream SHA-256 coverage.

The [release assets](https://github.com/yacinezah/torso21-reviewed-field-lines/releases/tag/v0.1.0) include the snapshot and its SHA-256.
The [public verification workflow](https://github.com/yacinezah/torso21-reviewed-field-lines/actions/workflows/verify.yml)
checks the tests, reviewed payloads and both manifest formats without downloading TORSO-21.

**CV/GitHub sentence:** Reviewed 2,400 TORSO-21 field-line masks and built a
reproducible, hash-verified overlay documenting 1,965 masks with class-label
changes and 435 with unchanged labels.
